orchontainerstrator
===================

Why this build exists: evaluate whether Mender Orchestrator can manage the
parts of a single device (base OS rootfs, a docker compose application, an
LLM model) as independently updated Components with ordered installs and
System-wide rollback, instead of one monolithic Artifact.

Order of outputs: internal evaluation -> scripted live demo -> Mender Hub article.

Status: all three stages (phase0, compose, llm) replay from scratch with
scripts/replay.sh. See README.md for how to build and run, docs/ for results.

Local builds on this host: symlink ~/kas/tyj-local.yml into my-qemuarm64/
and run with KAS_EXTRA=tyj-local.yml (shared DL_DIR and sstate); replay.sh
already runs kas with env -u TMPDIR.
